## [v0.2.0] - 2026-11-01

### Highlights

- The module is `github.com/grokify/pgutil`, PostgreSQL only, and its root package needs no database driver
- `provision` writes an idempotent `psql` script that provisions databases with owner and app roles, connection limits, timeouts and per-database `CONNECT` isolation, run as a managed server's non-superuser admin, and a query that verifies the server against the plan
- `scram` makes SCRAM-SHA-256 verifiers, so a role's password never reaches the server in plain text

### Breaking

- The module path is `github.com/grokify/pgutil`, formerly `github.com/grokify/godb`; the go-pg helpers in `github.com/grokify/godb/pgutil` are now in `github.com/grokify/pgutil/gopg` ([`540677b`](https://github.com/grokify/pgutil/commit/540677b))

### Added

- `ValidIdent`, `QuoteIdent` and `QuoteLiteral` for identifiers and literals ([`b7a06c7`](https://github.com/grokify/pgutil/commit/b7a06c7))
- `DSN`, `ParseDSN`, `WithDatabase` and `WithHost` for `postgres://` connection URLs ([`b7a06c7`](https://github.com/grokify/pgutil/commit/b7a06c7))
- `SQLState`, `IsUniqueViolation` and `IsInsufficientPrivilege`, reading any driver's SQLSTATE code without importing it ([`b7a06c7`](https://github.com/grokify/pgutil/commit/b7a06c7))
- `scram.Verifier`, `scram.VerifierWithSalt` and `scram.IsVerifier` for SCRAM-SHA-256 password verifiers as PostgreSQL stores them ([`18214ab`](https://github.com/grokify/pgutil/commit/18214ab))
- `provision.Plan` with `Script`, an idempotent `psql` script for databases, owner and app roles, limits, timeouts and `CONNECT` grants, with redaction of passwords for review, and `VerifySQL`, one row per difference from the plan ([`82c719b`](https://github.com/grokify/pgutil/commit/82c719b))
- `Plan.Reachable` names databases, such as a managed server's `template1`, that every role may reach without `VerifySQL` reporting it ([`559681e`](https://github.com/grokify/pgutil/commit/559681e))

### Deprecated

- The `gopg` package, built on go-pg, which is in maintenance mode; it is kept for existing callers ([`540677b`](https://github.com/grokify/pgutil/commit/540677b))

### Fixed

- `gopg.PgConn.Addr`'s JSON tag, misspelled `josn`, so the address is read from JSON ([`540677b`](https://github.com/grokify/pgutil/commit/540677b))
