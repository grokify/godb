# Release Notes - v0.1.1

## Overview

A maintenance release of `github.com/grokify/godb`. The API is unchanged
apart from `any` replacing `interface{}`, which callers need not notice.

## Changes

- Signatures use `any` in place of `interface{}`
- go-pg v10.11.2
- A build and test workflow, golangci-lint and its fixes, Dependabot, and Go 1.21 in the test matrix
- The MIT license

## Installation

```bash
go get github.com/grokify/godb@v0.1.1
```

The module is now `github.com/grokify/pgutil`; see the
[v0.2.0 release notes](v0.2.0.md) to upgrade.
