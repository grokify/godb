# Release Notes - v0.1.0

## Overview

The first release of `github.com/grokify/godb`: PostgreSQL helpers built on
go-pg, moved here from `github.com/grokify/mogo/database/pgutil`.

## Package pgutil

| Helper | What it does |
|---|---|
| `PgConn` | Connection settings read from JSON, encoded as a connection string or as go-pg options, with a client |
| `TagHistogramSQL`, `SelectTagHistogram`, `SelectTagHistogramResults` | Count each tag in an array column |
| `SelectArrayAny` | Select rows whose array column contains a value |
| `ErrIsDuplicateKey`, `NilifyErrDuplicateKey` | Recognize, or ignore, unique-key violations |

## Installation

```bash
go get github.com/grokify/godb@v0.1.0
```

The module is now `github.com/grokify/pgutil`, and these helpers are in its
deprecated `gopg` package; see the [v0.2.0 release notes](v0.2.0.md).
